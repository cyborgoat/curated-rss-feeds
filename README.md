# Curated RSS Feeds

Browse public RSS, Atom, and RDF feeds by subject. The catalog starts with mostly English feeds and labels the language of every entry.

## Getting started

[Download all feeds as OPML](https://raw.githubusercontent.com/cyborgoat/curated-rss-feeds/refs/heads/main/opml/all.opml) or choose a category below. In your feed reader, open its OPML import option and select the downloaded file. To subscribe to a single source, copy its **Feed** link from the category page.

In Inoreader, use **Add feed → Import feeds**. The full export groups feeds into category folders. A category export contains a flat list. [Inoreader import instructions](https://www.inoreader.com/help/basic/feeds-sources/can-i-import-feeds-from-another-rss-reader)
